# Chess Mastery

Personal chess coach: one skill graph that puzzles, lessons and your own games all feed, a daily session pitched just above your level, and a weekly 1% target. Plan: https://claude.ai/artifact/HWRCdE1cFD5UPyNeamfAon

## Phase 0 (this code)

- Rated tactics puzzles with click or drag moves, hints and solutions
- Skill graph: a Glicko-2 rating per skill (forks, pins, mating patterns, quiet moves, calculation depth…)
- Daily session of 15: reviews of past misses, the three weakest skills, mixed tactics
- Difficulty dial: puzzles served at skill rating + offset; offset moves ±25 to keep success near 80%
- Spaced repetition (FSRS via ts-fsrs) for every missed puzzle
- Weekly 1% target and rating trend
- Ladder sprint: 5 minutes, climbs a rung per solve, drops two per miss (unrated)
- Progress saved in the browser (localStorage)

## Run

```
npm install
npm run dev            # local dev server
SINGLE=1 npx vite build   # one self-contained dist/index.html
```

## Puzzles

`src/data/puzzles.json` is a starter set generated by `tools/gen_puzzles.py`: Stockfish self-play with injected human-like errors, keeping only positions where every one of the solver's moves is clearly the only winning move. Ratings are estimates from line length, quietness and search depth. Phase 1 swaps in a curated slice of the Lichess open puzzle database (CC0) via `tools/`.

## Layout

- `src/lib/glicko.ts` rating maths
- `src/lib/skills.ts` skill graph definition and theme → skill mapping
- `src/lib/store.ts` state, persistence, result recording, dial, FSRS
- `src/lib/trainer.ts` puzzle selection, weakness ranking, mastery states
- `src/components/PuzzleBoard.tsx` interactive puzzle board
- `src/screens/` Today, Skills, session runner, ladder, onboarding
